# Yale-Peaked-Hackathon-2026
### ⚛️ Peaked Circuits Solver – Quantum Hackathon

This repository contains my solution for the **Peaked Circuits Quantum Hackathon**, where the objective is to identify the most probable bitstring (the *peak*) generated by a given quantum circuit.

---

## 🚀 Problem Overview

In this challenge, participants are given quantum circuits in `.qasm` format. Each circuit prepares a quantum state where:

* One specific bitstring has a **significantly higher probability**
* All other bitstrings have comparatively lower probabilities

🎯 **Goal:**
Find the hidden *peak bitstring* by simulating or analyzing the circuit.

---

## 🧠 Approach

The solution follows a practical and scalable strategy:

### 1. Circuit Loading

* Parse `.qasm` files into quantum circuits

### 2. Simulation

* Use quantum simulators to execute the circuit
* Perform multiple measurements (*shots*) to estimate probabilities

### 3. Peak Detection

* Count measurement outcomes
* Identify the bitstring with the highest frequency

### 4. Optimization (for larger circuits)

* Use statevector simulation when feasible
* Fall back to sampling for larger qubit systems
* Analyze circuit structure for faster inference

* Python 🐍
